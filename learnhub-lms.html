LearnHub LMS

> Learning Management System

LearnHub LMS is an ASP.NET Core MVC learning management system project by Sudipta Sikder, combining application development with authentication, database access and role-based access control.

$ technology_stack

ASP.NET Core MVCC#ADO.NETSQL ServerBCryptRBAC

$ security_features

The project includes password hashing with BCrypt, cookie-based login handling and role-based access control to separate user capabilities.

$ architecture

The MVC structure separates presentation, application logic and data access concerns while ADO.NET and SQL Server provide the database layer.
